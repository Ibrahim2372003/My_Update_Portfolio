
# My Portfolio

A personal portfolio built with Next.js and React to showcase my projects, technical skills, and professional experience.

## Tech Stack

- Next.js 14
- React 18
- Tailwind CSS
- Framer Motion
- JavaScript

## Getting Started

### Requirements

- Node.js
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
